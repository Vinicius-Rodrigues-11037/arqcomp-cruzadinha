# Memória da Arquitetura

Jogo da memória em HTML, CSS e JavaScript puros para treinar termos de Arquitetura Computacional (Atividade Avaliativa III, Sprint 3).

## Como jogar

1. Clique em uma carta para virá-la e depois em outra.
2. Cada par é formado por uma **sigla/termo** (carta escura) e a **descrição** dele (carta clara).
3. Se as duas cartas combinam, elas ficam verdes. Se não, piscam em vermelho e viram de volta.
4. O jogo termina quando você encontra os 14 pares. O contador mostra os pares e as tentativas.
5. Use o botão **Reiniciar** para embaralhar e começar de novo.

## Termos e pistas

| Termo | Pista |
|-------|-------|
| CPU | Busca e executa as instruções do computador. |
| ULA | Faz as contas e as operações lógicas dentro do processador. |
| UC | Lê cada instrução e dá as ordens aos outros componentes. |
| Registrador | Memória minúscula e muito rápida dentro da CPU; o acumulador é um exemplo. |
| RAM | Memória de trabalho, volátil: guarda programas em execução e seus dados. |
| ROM | Memória não volátil que guarda o firmware do equipamento. |
| EEPROM | Memória pequena do Arduino cujos dados sobrevivem ao desligamento. |
| Flash | Mesma tecnologia do pendrive; guarda o programa do Arduino. |
| Cache | Guarda cópia do que a CPU usou há pouco, para acesso veloz. |
| DMA | Um controlador copia dados entre dispositivo e memória sem a CPU mover cada byte. |
| Microcontrolador | Chip com CPU, memória e entrada e saída juntos; o ATmega328P é um. |
| Barramento | Conjunto de fios compartilhado que liga CPU, memória e entrada e saída. |
| Clock | Relógio interno que dá o ritmo da CPU; no Arduino Uno, 16 MHz. |
| Firmware | Programa gravado no chip que define o comportamento do equipamento. |
